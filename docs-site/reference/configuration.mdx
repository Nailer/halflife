## `halflife.toml`

Required in every scan target.

```toml
[subject]
name = "string"           # display name; NOT part of circuit_hash
repository = "string"     # URL or identifier; part of circuit_hash
commit = "string"         # exact revision; part of circuit_hash
proof_system = "string"   # free text; part of circuit_hash
```

All four keys are required. Halflife's own root manifest:

```toml
[subject]
name = "halflife"
repository = "https://github.com/Nailer/halflife"
commit = "self"
proof_system = "none"
```

<Accordion title="In plain terms" icon="lightbulb">
Every project you scan needs this tiny file to say what it is. Changing the name is harmless. Changing the repository, commit, or proof system creates a different identity.
</Accordion>

## `Cargo.lock`

Any Cargo lockfile version that has `[[package]]` tables with `name`, `version`, and optionally `source` and `checksum`. A package is **from a registry** if `source` starts with `registry+`. (The browser check also accepts `sparse+`.)

## Issuer key file

A JSON array of exactly 64 integers: `secret[0..32] ‖ public[32..64]`. Produced by `halflife keygen` or `solana-keygen`. Must be internally consistent.

## OSV snapshot

A JSON object mapping `"name@version"` to an array of advisory IDs. Only matching entries appear. Generated by `scripts/build-snapshot.py`.

## Registry file

SQLite, default `halflife.db`, created on first use with the schema applied idempotently (`CREATE … IF NOT EXISTS`). Foreign keys are on.

## Environment variables

| Variable | Used by | Default |
|---|---|---|
| `OFFLINE` | `scripts/demo.sh` | unset (online). Set to anything to use `--offline` |
| `HALFLIFE_ISSUER` | `scripts/self-passport.sh` | `issuer.json` |
| `EVM_RPC` | `scripts/cross-chain.sh` | `http://127.0.0.1:8545` |
| `EVM_KEY` | `scripts/cross-chain.sh` | anvil account 0 (local only) |

## Pinned constants

| Constant | Value | Defined in |
|---|---|---|
| `SIGNING_DOMAIN` | `halflife-passport-v1` | core, Solana program, Node impl |
| `PASSPORT_VERSION` | `1` | core |
| `PASSPORT_CORE_LEN` / `CORE_LEN` | `125` | core, Solana, EVM, Node |
| `MAX_CLOCK_SKEW_SECS` | `300` | core, Solana |
| `REGISTER_DOMAIN` | `halflife-register-issuer-v1` | Solana program |
| circuit-ID domain | `halflife-circuit-id-v1\0` | core |
| OSV endpoint | `https://api.osv.dev/v1/querybatch` | lineage, control room |
| OSV batch size | 400 (CLI) / 500 (browser) | lineage, `Check.tsx` |
| Default TTL | 86,400 s (CLI) / 45 s (drills) | CLI, exercise |

<Warning>
These constants must match across runtimes. Changing one is a **format change** and invalidates every published passport and conformance vector.
</Warning>
