`Evidence` is the full, auditable, off-chain record a passport is issued over. It's bound to the passport by `evidence_hash = SHA-256(canonical JSON)`.

<Accordion title="In plain terms" icon="lightbulb">
This is the detailed report behind the label. It lists every library checked and every problem found. The label carries a fingerprint of this report so the two can always be matched.
</Accordion>

## Canonicalization

Before hashing, `normalize()`:

1. Sorts `dependencies` (by name, then version, then checksum, then advisories).
2. Sorts and de-duplicates each `advisories` list.
3. Sorts `methods` by `id`.

Then `serde_json::to_vec` serializes it compactly, with no whitespace, in declared field order.

## Derived values

| Value | Definition |
|---|---|
| `advisory_count()` | Sum of `advisories.len()` across dependencies (capped at `u16::MAX` in the core) |
| `derive_status()` | `INVALID` if `advisory_count > 0`, else `VALID` |
| `hash()` | `SHA-256(canonical_json)` → `evidence_hash` |
| `circuit_hash()` | See [Circuit identity](/concepts/circuit-identity) |
| `is_public()` | `disclosure == PUBLIC` |

## Binding rule

A verifier given both artifacts **MUST** confirm that the evidence reproduces **both** `evidence_hash` and `circuit_hash`.
