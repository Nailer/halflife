`halflife export` writes the entire system state as one JSON document. The control room is a **client** of this file, not a second source of truth.

<Accordion title="In plain terms" icon="lightbulb">
This is the single data file the dashboard reads. Everything the website shows comes from here, so this page describes each part of it.
</Accordion>

## `Circuit`

| Field | Type | Notes |
|---|---|---|
| `circuitHash` | hex string | |
| `name`, `repository`, `commit`, `proofSystem` | string | From `halflife.toml` |
| `dependencies` | number | Closure size |
| `status` | `VALID \| STALE \| INVALID \| NONE` | Resolved at export time |
| `capability` | number | 0 if `NONE` |
| `sequence`, `expiresAt` | string | 64-bit values as strings |
| `issuer` | string | base58, or empty if `NONE` |

## `Dependency`

| Field | Type |
|---|---|
| `name`, `version` | string |
| `circuits` | number of visible circuits reaching it |
| `affected`, `clean` | numbers from projection |
| `advisories` | string[] |

## `HyperlaneDispatch`

| Field | Type |
|---|---|
| `transaction`, `mailbox`, `mailbox_message_account`, `message_id`, `sender`, `recipient`, `circuit_hash` | string |
| `slot`, `nonce`, `origin_domain`, `destination_domain` | number |
| `recipient_is_placeholder` | boolean |
| `limits` | string[] (stated limits travel with the data) |

## Public vs operator

A public export **omits** any circuit whose latest passport isn't `PUBLIC` (including circuits with no passport) and computes `dependencies` with `Audience::Public`. Nothing is redacted, so nothing reveals what was withheld.
