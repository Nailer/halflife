## Instructions

### `register_issuer(key: [u8; 32])`

Registers an issuer with **proof of possession**.

| Account | Constraints |
|---|---|
| `issuer` | `init`, PDA `["issuer", key]`, payer = authority |
| `authority` | `Signer`, `mut` |
| `instructions` | Instructions sysvar |
| `system_program` | |

**Requires** instruction 0 to be an Ed25519 verify, by `key`, over `"halflife-register-issuer-v1" ‖ authority`. Emits `IssuerRegistered { key, at }`.

### `init_config()`

Creates `Config` at `["config"]`. **The caller becomes admin.** First-caller-wins, so call it in the same step as deployment. Emits `AdminChanged { previous: default, current }`.

### `set_admin(new_admin: Pubkey)`

Admin only (`NotAdmin`). Hands the admin role to another key, for example a multisig. Emits `AdminChanged`.

### `revoke_issuer()`

`has_one = authority`. Sets `revoked_at = now`. Forward-only. Fails with `AlreadyRevoked` if already revoked. Emits `IssuerRevoked`.

### `publish(core: [u8; 125])`

Permissionless. Verifies the issuer's off-chain signature.

| Account | Constraints |
|---|---|
| `passport` | `init_if_needed`, PDA `["passport", core[1..33], core[33..65]]` |
| `issuer` | PDA `["issuer", core[33..65]]` |
| `payer` | `Signer`, `mut` |
| `instructions` | Instructions sysvar |
| `system_program` | |

**Requires** instruction 0 to be an Ed25519 verify, by the core's issuer, over `"halflife-passport-v1" ‖ core`. Emits `PassportPublished { circuit_hash, issuer, sequence, status, expires_at }`. See [validation order](/architecture/solana-enforcement#publish-validation-order).

### `set_route(destination_domain: u32, recipient: [u8; 32], mailbox: Pubkey)`

Admin only, and the `mailbox` must be allowlisted. `init_if_needed` at `["route", domain_le]`. Emits `RouteSet`.

### `dispatch()`

Reads the passport, CPIs into the route's mailbox signed by the dispatch-authority PDA, with the 125-byte body.

| Account | Notes |
|---|---|
| `passport` | Read-only, must exist |
| `route` | PDA `["route", domain_le]` |
| `outbox` | Hyperlane outbox PDA (`["hyperlane", "-", "outbox"]` under the mailbox) |
| `dispatch_authority` | PDA `["hyperlane_dispatcher", "-", "dispatch_authority"]`, signs via `invoke_signed` |
| `payer` | Signer |
| `unique_message` | Fresh keypair, signer |
| `dispatched_message` | PDA derived by the mailbox |
| `mailbox_program` | Must equal `route.mailbox` **and** be allowlisted |
| `spl_noop` | `noopb9bkMVfRPU8AsbpTUg8AQkHtKwMYZiFUjNRtMmV` |
| `system_program` | |

Emits `PassportDispatched { circuit_hash, issuer, sequence, destination_domain }`.
