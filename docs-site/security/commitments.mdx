## Discipline rules

| # | Commitment | How to check |
|---|---|---|
| D1 | **No tier claimed without measurement**. C1 only until C2+ recall is published. | `Capability::C1` hardcoded in scan |
| D2 | Every published number is reproducible from a committed script | `halflife-bench`, exercise ledgers |
| D3 | The deterministic path stays model-free and reproducible offline | `--offline`, pinned snapshot |
| D4 | Negative results are published, including poor engine recall | Self-passport `INVALID` |
| D5 | **CLI before UI**. A capability not in the CLI isn't built. | Control room renders `export` |
| D6 | No manufactured scale: small, real fleet only | 8 systems, never 47 |
| D7 | **Measured, not simulated**. No displayed timing from a predetermined script. | Event ledger |
| D8 | Embargo via staleness is quiet, not confidential | Disclosure policy |

## Ecosystem necessity

| # | Commitment | Test |
|---|---|---|
| E1 | **Zcash** is the real cryptographic target | Fixtures span the real advisory boundary with genuine checksums |
| E2 | **Solana** is justified by a measured CU cost, not convenience | Benchmark publishes the number whatever it says |

## Scope discipline

| # | Commitment |
|---|---|
| S1 | Two fire-drill scenarios only: dependency compromise and relayer censorship |
| S2 | Issuer compromise and deployment drift are **defined and not armed** |
| S3 | Projection claims **circuits only** until consumer registration exists |
| S4 | Artifact identity (P4B) must not block dependency intelligence (P4A) |
| S5 | No extra chain, token, DAO, marketplace, insurance layer, security score, or agent swarm |
| S6 | The verification engine is sequenced last, so its research risk can't sink the project |
