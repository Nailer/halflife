This guide reproduces the **origin leg** of propagation against Hyperlane's **deployed devnet mailbox**.

<Accordion title="In plain terms" icon="lightbulb">
These steps send a passport label from Solana into Hyperlane's real message system on the test network, then read Hyperlane's own record back to prove the message was accepted, that it came from the Halflife program, and that it carries exactly the right 125 bytes.
</Accordion>

<Steps>
  <Step title="Initialise config (once, at deployment)">
    ```bash
    ./target/release/halflife-exercise init-config --payer solana/deploy-keypair.json
    ```
    The caller becomes **admin**. `init_config` is first-caller-wins, so run it in the **same step as deployment**. If config already exists, the command prints the current admin and exits.
  </Step>
  <Step title="Set a route (admin only)">
    ```bash
    ./target/release/halflife-exercise set-route \
      --domain 84532 \
      --mailbox 5yM5YrrzHCrp4ZPLKN9Y2eUAqEWsTbBqaorgbngQcR54
      # --recipient 0x<bytes32 destination registry>  (defaults to a 0xeeee… placeholder)
    ```
    This fails with `NotAdmin` if the signer isn't admin, or `UnknownMailbox` if the mailbox isn't allowlisted.
  </Step>
  <Step title="Ensure a passport exists">
    ```bash
    ./target/release/halflife-exercise publish <circuit_hash_hex> --status valid --ttl 86400
    ```
  </Step>
  <Step title="Dispatch">
    ```bash
    ./target/release/halflife-exercise dispatch [<circuit_hash_hex>] --domain 84532
    ```
    This writes `exercises/hyperlane-dispatch-<unix>.json`.
  </Step>
  <Step title="Verify independently">
    ```bash
    ./target/release/halflife-exercise verify-dispatch exercises/hyperlane-dispatch-*.json
    ```
    This re-reads the **mailbox-owned** message account and checks that the transaction succeeded, the sender is the passport program, and the body is the recorded 125 bytes.
  </Step>
</Steps>
