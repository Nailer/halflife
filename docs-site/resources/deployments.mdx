<Accordion title="In plain terms" icon="lightbulb">
These are the places where Halflife is running right now: the website, and the programs on Solana's public test network. Each address can be looked up on a blockchain explorer.
</Accordion>

## Control room

**[halflife-control-room.vercel.app](https://halflife-control-room.vercel.app)**: a static build, redeployed with `./scripts/deploy-ui.sh`. The `PUBLIC` / `OPERATOR` toggle loads different exports.
